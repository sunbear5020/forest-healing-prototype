# 숲결 맞춤 추천 엔진 — 구조와 자료 (현행판: `engine/soopgyeol-engine.js`의 VERSION, 2026-11-17 기준 0.7.0)

사용자의 **지금 상태·니즈**를 **시설 환경(고정/평년/실황)**, **효과 근거**와 맞춰 치유의 숲 방문을 추천하고,
방문이 어려우면 **디지털 프로그램(개발 중, 자리만) → 집 근처 수관 피복이 넉넉한 공원 → 산림공원 → 도시숲(자료 확보 시) → 가까운 산림** 순으로 안내합니다.
GitHub Pages에서 그대로 돌아가는 정적 구성이며, 입력값은 기본적으로 브라우저 안에서만 계산합니다(저장·전송 없음). 서버 계산은 `config.js`에 개인정보 처리방침 주소가 있을 때만 켜집니다.

## 1. 처리 흐름

```
입력(자가점검 6영역·목적·걷기·이동 허용·방문일·출발 위치·방문 가능 여부)
  │
  ├─① 안전 확인 ─ 자해 생각 → 상담전화(109, 1577-0199) 먼저, 대안 경로 강조
  ├─② 상태 프로필 ─ 영역 가중치 w(스트레스·불안·우울감·피로·수면·호흡기)
  ├─③ 시설별 평가(44곳: 효과측정 9곳, 나머지 유사 시설 추정)
  │    E 효과: 설문 효과모형(시설×영역, 10~90% 구간; 월별 차이는 표시만, v0.7.0) → 없으면 측정기관 중앙값(유사 시설 추정)
  │             + 효과모형 환경항은 Benjamini–Hochberg 보정(q<0.05) 후 남은 항만 반영
               → 2026-11-15 현재 29개 중 명목 p<0.05 4개, 보정 후 0개 = 반영 없음(v0.1은 보정 없이 p<0.05를 써서 과대 반영)
  │    V 환경: 방문일 예보(③층) → 없으면 최근 5년 월평균(②층) + 수관 피복·경사(①층) + 예측 NVOC ±3점(2018 측정값은 표시만, v0.7.0)
  │             폭염(33℃)·강풍(14 m/s)·PM2.5 나쁨(36) 안전 규칙, 나머지 계수는 시연값
  │    A 접근: 출발점-시설 거리 → 이동시간 추정, 허용시간 초과 시 제외
  ├─④ 종합 = 0.5·E + 0.3·V + 0.2·A(시연값), 몬테카를로 400회로 점수·순위 범위(10~90%, 효과 불확실성만 반영)
  ├─④' 나쁜 날씨(PM2.5 나쁨·비)면 실내 대체 시설 있는 곳을 점수보다 먼저(v0.3, 시연 규칙)
  ├─④'' 불확실하면 가까운 곳 우선(v0.4): 같은 단계 안에서 최고점 시설보다 5점 넘게 낮을 확률이 80% 미만인 시설 중 이동시간이 가장 짧은 곳을 앞에(효과 구간 정규 근사, 시드 무관). 가상 판정 후 추가한 사후 규칙. v0.7.0부터 효과 근거 등급이 최고점 시설보다 낮은 시설은 앞당기지 않음
  ├─⑤ 프로그램(목적 태그·난이도·기상 → 실내 전환), 주변 산림 20 km, 관광 연계 자리
  └─⑥ 대체 경로: 디지털 프로그램 자리(개발 중) / 공원(수관 ≥30%, ≥1 ha, 2→5→10 km) / 산림공원(수관 ≥60%, ≥10 ha) / 도시숲(자료 없음, 자리만) / 가까운 휴양림·치유의숲
       강풍·폭염·PM2.5 나쁨이면 실외 자제 안내를 먼저(v0.3)
```

지역 건강 지표(지역사회건강조사)는 **출발 시군구의 맥락 표시**에만 쓰고 개인 점수에는 넣지 않습니다(생태학적 오류 방지).

## 4. 결과에 함께 나오는 기록(v0.2)

- `config`: 엔진 버전, 계수표 해시(`paramsHash`), seed, 반복 수, 효과모형 버전·적합 시각, 예보 기준시각, 시설·공원·산림 수.
- `warnings`: 자료 누락(효과모형·예보·시설 기상)과 입력 보정을 조용히 넘기지 않고 표시.
- `evidenceAudit.envTerms`: 환경항 검정 수, 명목 유의 수, 보정 후 유지 수.
- 시설 순서를 id로 고정하고 동점은 id로 정해, 입력 순서가 결과를 바꾸지 않음.

## 5. 해석 제한

- 효과 값은 대조군 없는 사전-사후 변화이며 인과 효과가 아닙니다.
- 시설 간 효과 차이에는 사업·대상군 구성이 섞여 있습니다. 환경 때문이라고 해석하면 안 됩니다.
- 효과모형 교차검증에서 환경지표 추가는 예측력을 높이지 못했습니다(R² 0.648→0.642). 환경 점수는 주로 안전·쾌적 규칙입니다.
- 수면·호흡기는 결과 척도가 없어 효과를 계산하지 않습니다(환경 노출만 반영, 근거 수준 낮음).
- 효과측정 자료가 없는 시설은 측정기관 중앙값을 같게 쓰고 범위를 넓게 둡니다. 효과로는 서로 구분되지 않습니다.
- 공원 수관 피복은 공원 경계가 아닌 대표 좌표 원형 근사입니다. 공원 수종은 아직 결합하지 않았습니다.
- 에어코리아 측정소 위치 API(MsrstnInfoInqireSvc)가 미승인이라 PM2.5는 시도 중앙값입니다.
- 자가점검은 진단이나 표준화된 선별도구가 아닙니다.
- 규칙 판정(`tests/eval`) 통과는 엔진이 자기 규칙을 지킨다는 뜻일 뿐, 추천이 사람에게 맞다는 근거가 아닙니다. 전문가 판정 전입니다.
- 후보가 4곳 이상인 사례 133건에서 엔진 상위 3곳은 가까운 순 3곳과 평균 2.35곳 겹치고, 35%는 구성이 같습니다. 현재 개인화의 몫은 크지 않습니다.
- 산음·장성·서귀포·만연산·남해 5곳의 월평균 기후는 인접 ASOS(양평·고창·서귀포·광주·남해) 2021~2025 일자료이며 표고 보정이 없습니다(`scripts/build/climate_asos.py`).

## 시설 범위 변경(2026-11-16)
- 추천 대상: 진흥원 운영시설 13곳(산림치유원 1, 숲체원 5, 국립치유의숲 7) + 공립·기타 치유의숲 5곳 + **산림청 치유의숲 현황(15107928)·좌표(15110279)의 나머지 26곳(hf_*)** = 44곳.
- hf_* 시설은 프로그램·측정 자료가 없어 효과는 측정기관 중앙값('유사 시설로 추정'), 환경은 공개 좌표 기반만 쓴다. 시군구 건강지표·임상 비율은 아직 없음.
- 국립춘천·나주숲체원은 진흥원 소속기관정보(15061976)에도 없어 좌표 미확보.
- 자연휴양림(전국휴양림표준데이터 15013111)은 대체 경로 '가까운 산림'에만 두고 "산림치유 프로그램 미운영"으로 표시. 효과 점수는 계산하지 않음.

## 숲 취향·경관 정보(v0.5, 2026-11-16)

- 근거: 임상유형별 메타분석(기분 지표, 침엽−혼효 +0.02 [−0.21, +0.26])에서 숲 종류 간 효과 차이가 확인되지 않음. 경관 선호·회복감 연구는 혼효림 쪽으로 기울지만 근거가 약함. 그래서 숲 종류는 **효과 점수에 넣지 않는다**.
- 입력: `forestTaste` = `conifer` | `broadleaf` | `mixed` | 빈값(상관없음). 화면에서는 맑은 날 숲길 사진 3장(위키미디어 공용, CC BY-SA, 출처 표기)으로 고른다. 사진은 예시이며 시설 사진이 아니다.
- 취향 일치: 반경 5 km 임상 구성에서 해당 유형 비율이 임상 자료가 있는 시설들 중 상위 3분위(분위수 2/3) 이상이면 일치.
- 순서 반영: 최고점과 `TASTE_BAND`(3점) 이내이고 확실히 다르지 않은 후보 가운데 취향 일치 시설을 먼저 둔다. 총점은 바뀌지 않는다(테스트로 확인).
- 경관 배지: '혼효림 많은 편'(혼효 비율 상위 3분위), '단풍 경관 시기'(10·11월, 활엽 비율 상위 3분위). 효과 근거가 아니라 경관 정보로 표시.
- 꽃가루 안내: 4·5월 활엽 비율 40% 이상이면 참나무·자작나무·오리나무 꽃가루, 제주(위도 33.7 미만) 2~4월은 삼나무·편백 꽃가루 안내.

## 예측 피톤치드(NVOC) 정보와 환경 점수 소폭 반영(v0.6, 2026-11-16)

- 식: 원문에서 계수를 확인한 식만 사용. 자작나무(Kim·Park·Kwak 2020, IJERPH 17:7875, R² 0.60), 잣나무 600·700본/ha(Kim et al. 2021, Atmosphere 12:1113, R² 0.57·0.76). PAR·사진 지표가 필요한 식(대나무, 잣나무 900·1000본/ha, 삼나무·편백 겨울 식)은 쓰지 않음.
- 적용 시설: 임상도에서 시설 1 km 안에 해당 수종 ≥1 ha 폴리곤이 있는 시설(`facility_env.json` → `species_stands`, 가공 집계값만 공개).
- 입력: 단기예보 일평균 기온(최고·최저 평균), 습도, 풍속(최대풍속, 평균이 아님).
- 적용 범위: 측정 계절 밖(자작나무 5~7월 외, 잣나무 3~9월 외)은 계산하지 않음. 모형값이 0 이하면 '적용 범위 밖'.
- 점수: 같은 달 평소 기후(최근 5년 월평균)로 계산한 값 대비 비율 r에 대해 환경 점수 += clamp(10·(r−1), −3, +3). 효과 점수에는 넣지 않음(농도→건강 효과 근거 미확인). 2026-11-16 사용자 결정.
- 근거등급: 낮음(단일 장소·짧은 기간, 외부 검증 없음).
- 상세: 프로젝트 문서 `연구설계/피톤치드예측/02_NVOC_예측모형_검토_및_적용계획.md`.

## v0.6.1 기온 평년값(②층) 교체와 편차 계산 (2026-11-16)

- **결정(사용자 승인 2026-11-15)**: 주분석 평년값 = 기상청 공식 일평년값(1991~2020)이 있는 관측소는 공식값, 없는 AWS 8곳은 자체 조화회귀 평년값 '현 위치~2025 확장판'. 강릉성산(대관령)·대덕(김천)은 10년 기준 미달이라 강릉·거창 ASOS 공식값으로 대체. 1991~2020(현 위치 구간)판은 민감도.
- **방법**: `scripts/build/climate_normals.py`가 프로젝트 폴더 `자료/kma_aws/`의 일평년값(doy)을 달별 평균해 `facility_env.json`의 `climate.normal`(주분석)과 `climate.normal.sensitivity`(민감도)에 넣음. 기온은 기존과 같은 표고 보정(0.65 ℃/100 m). ASOS 대체 2곳은 (관측소 표고 − 시설 대표점 표고)로 새로 보정(강릉 −1.54 ℃, 거창 −3.45 ℃).
- **엔진**: 예보·시나리오일 때 `env.anom = 예보 평균기온 − 평년값`(평년값 없으면 2021~2025 월평균)을 계산해 추천 이유에 "평균기온 평년 대비 ±x℃(근거)"로 표시. 효과모형의 기온 편차 항도 같은 기준을 씀. 현재 이 항은 BH 보정 후 유의하지 않아 점수에는 영향이 없음(평가 결과 불변).
- **결과(13개 시설, 연평균 기온, 2026-11-17 정정)**: 2021~2025 월평균(60개월 전체로 재계산)이 주분석 평년값보다 평균 0.61 ℃ 높음(범위 +0.36~+1.12 ℃; 예산 +1.12, 양평 +0.83, 대운산·곡성 +0.74). 이전 판의 '평균 0.17 ℃(−0.09~+0.68)'는 월평균이 2~3년치로만 계산된 값이라 틀렸음(가상 전문가 검토 E3-01). 공식 평년값(1991~2020) 5곳 평균 +0.79 ℃, 자체 확장판 6곳 평균 약 +0.5 ℃로 평년값 기준기간 차이가 편차 수준에 약 0.3 ℃ 남음(검토 E3-06). 확장판은 1991~2020판보다 0.17~0.42 ℃ 높음(대관령 민감도 대비 −0.39). 즉 확장판은 분석기간이 섞여 편차를 약간 작게 만든다는 우려가 수치로 확인됨.
- **한계**: 일평균기온 평년값의 매시 보정(tavg_offset)은 커밋 c1ce5df에서 매시자료 60개월로 다시 계산했다고 기록됨(이 문서는 그 전 54개월 기준으로 쓰였음). 예보 평균기온은 (최고+최저)/2라 24시간 평균인 평년값보다 0.3~1 ℃ 높게 나올 수 있음(검토 E3-02, v0.7.0부터 최저기온 예보가 없으면 편차를 계산하지 않음). 김천(거창 ASOS)은 22 km·표고차 534 m로 대표성이 낮음. 상대습도 평년값은 공식 관측소만 있음.
