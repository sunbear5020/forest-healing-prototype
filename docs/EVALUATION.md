## 1. "좋은 추천"의 정의(구성개념)

추천이 좋다는 것은 다음 다섯 가지를 **모두** 만족한다는 뜻으로 정합니다.

| 차원 | 뜻 | 측정 방법 |
| --- | --- | --- |
| 안전 적절성 | 위험 신호(자해 생각, 매우 심한 우울·불안, 폭염·강풍·미세먼지)에 맞는 안내를 먼저 준다 | 규칙 판정(§3 S·H) |
| 과잉회피 없음 | 위험 신호가 없으면 막지 않고 추천을 준다. 위험 신호가 있어도 숲 이용 자체를 거절하지 않고 상담·대안을 함께 준다 | 규칙 판정(§3 S2·S3) |
| 니즈 부합 | 고른 영역·목적·걷기 조건·이동 허용시간에 맞는다 | 규칙 판정(§3 A·N) + 전문가 판정(§5) |
| 불확실성 정직성 | 점수·순위에 범위가 있고, 근거 등급(측정/유사 추정/문헌)과 해석 제한이 보인다 | 규칙 판정(§3 U) |
| 일관성 | 무관한 세부(입력 순서, 난수 seed)에 결과가 흔들리지 않고, 조건을 완화하면 선택지가 줄지 않는다 | 불변성·단조성 판정(§3 I·M) |

규칙 판정(§3)은 **엔진이 스스로 정한 규칙을 지키는지**(내적 타당도)만 봅니다.
추천이 실제로 사람에게 맞는지(외적 타당도)는 §5 전문가 블라인드 판정으로만 말할 수 있으며, 그 전에는 "검증됨"이라고 쓰지 않습니다.

## 2. 시나리오 설계(교차 요인)

모든 요인을 완전 교차합니다(일부 조합만 고르지 않음).

| 요인 | 수준 |
| --- | --- |
| 상태 프로필 | 8개: 스트레스 높음, 우울 높음, 불안 높음, 피로 높음, 수면만, 호흡기만, 전반 경미, 전반 매우 심함(우울·불안 4) |
| 자해 생각 | 없음 / 있음 (위험–일반 쌍) |
| 출발지 | 5곳: 서울, 부산, 광주, 강릉, 제주 |
| 환경 시나리오 | 5개: 보통(20℃), 폭염(35℃), 강풍(16 m/s), PM2.5 나쁨, 비 |
| 방문 가능 | 가능 / 불가 |
| 이동 허용 | 1.5시간 / 3시간 |

8 × 2 × 5 × 5 × 2 × 2 = **1,600건**. 목적(purpose)은 프로필의 주 영역에서 정하고, 걷기는 '보통'으로 고정합니다.

## 3. 판정 기준(이진)과 통과선

각 사례에 해당하는 기준만 판정합니다(해당 없음은 분모에서 뺌). 통과율은 Wilson 95% 구간과 함께 보고합니다.

| ID | 적용 조건 | 통과 조건 | 통과선 |
| --- | --- | --- | --- |
| S1 | 자해 생각 있음 | 안전 수준 `urgent`, 109·1577-0199 포함, 대체 경로 강조 | 100% |
| S2 | 자해 없음·우울/불안 4 미만·환경 보통·방문 가능·3시간 | 안전 수준 `ok`, 추천 3곳 이상, 대체 경로 강조 안 함 | 100% |
| S3 | 자해 없음·우울 또는 불안 4 | 안전 수준 `caution`, 상담 연락처 1개 이상, 추천을 거절하지 않음(이동·환경 제외가 없는 한 1곳 이상) | 100% |
| H1 | 폭염 | 추천된 모든 시설이 실내 대체 시설 보유 | 100% |
| H2 | 강풍 | 추천 0곳이고 대체 경로(공원 또는 산림) 1곳 이상 강조 | 100% |
| H3 | PM2.5 나쁨·호흡기 가중치 ≥ 0.25 | 추천된 모든 시설이 실내 대체 시설 보유 | 100% |
| H4 | 비·PM2.5 나쁨·폭염·강풍 | 추천 시설의 프로그램이 실내 전환 표시(`switchedIndoor`) | 100% |
| A1 | 전체 | 모든 추천 시설의 이동시간 ≤ 허용시간 | 100% |
| A2 | 방문 불가 | 대체 경로 강조, 공원은 모두 수관 피복 ≥ 30%, 산림 1곳 이상 | 100% |
| A3 | 추천 0곳 | 대체 경로 강조(빈 화면으로 끝내지 않음) | 100% |
| N1 | 환경 보통·추천 시설에 목적 태그가 붙은 프로그램이 있음 | 첫 프로그램이 주 목적 태그를 가짐 | ≥ 95% |
| N2 | 전체 | 효과모형 영역(스트레스·불안·우울·피로)을 고르면 효과 점수 있음, 수면·호흡기만이면 효과 점수 없음 | 100% |
| U1 | 추천 1곳 이상 | 모든 추천에 순위 범위·점수 범위(점수 ±1 포함)·근거 등급·이유 2개 이상 | 100% |
| U2 | 전체 | 인과 아님 고지, 설정 기록(`engine`, `paramsHash`, 효과모형 버전) 있음 | 100% |
| I1 | 전체 | 시설·산림·공원 목록 순서를 섞어도 추천 시설·점수 동일 | 100% |
| I2 | 전체 | seed를 바꿔도 추천 시설 순서·점수(점추정) 동일 | 100% |
| M1 | 전체 | 이동 허용을 1.5→3시간으로 늘려도 후보(제외 안 된 시설) 집합이 줄지 않음 | 100% |
| M2 | 전체 | PM2.5를 보통→나쁨으로 바꿨을 때 어느 시설의 환경 점수도 올라가지 않음 | 100% |

판정 결과는 **통과·실패를 모두** 보고합니다. 실패가 나오면 사례 입력을 그대로 남겨 재현할 수 있게 합니다.

## 4. 함께 보고할 것(통과·실패와 무관)

- 효과모형 환경항: 검정 수, 명목 p<0.05 수, Benjamini–Hochberg(q<0.05) 후 남은 수. 남은 것이 없으면 "효과 점수에 반영하지 않음"을 결과로 적습니다(무결과도 결과).
- 시설별 근거 등급 분포(측정 / 유사 시설 추정 / 없음)와 기상 자료 없는 시설 목록.
- 순위 범위 폭의 분포(상위 5곳 기준).
- 실행 설정: 엔진 버전, `paramsHash`, seed, 반복 수, 효과모형 버전·적합 시각, 예보 기준시각.

## 5. 전문가 블라인드 판정(외적 타당도)

- 사례: §2 교차표에서 층화 무작위로 **100건**(자해 있음 10건 포함). 생성: `node tests/eval/make_expert_cases.mjs`.
- 비교: 사례마다 A·B 두 추천 목록(엔진 상위 3곳 vs **가까운 순 상위 3곳** 기준선)을 무작위 순서로 보여 줍니다. 어느 쪽이 엔진인지는 별도 정답표(`answer_key.csv`)에만 있고 판정자에게 주지 않습니다. 정답표는 저장소에 올리지 않습니다(`.gitignore`). 생성 스크립트를 다시 돌리면 같은 정답표가 나오므로, 판정자에게는 저장소가 아닌 CSV 파일만 전달합니다.
- 판정자: 산림치유지도사 또는 정신건강 분야 전문가 **2인 이상**, 서로 독립 판정.
- 판정 항목: (1) A·B 각각 적절성 3단계(0 부적절, 1 일부 적절, 2 적절), (2) 둘 중 더 나은 쪽(A/B/같음), (3) 안전 안내가 적절한지(예/아니오).
- 분석(`python tests/eval/kappa.py`): 판정자 간 Cohen's κ(이진 항목), 가중 κ(이차 가중, 3단계), 부트스트랩 95% 구간 2,000회. 엔진 선호율과 Wilson 95% 구간.
- 사전 통과선: 판정자 간 가중 κ ≥ 0.60(이보다 낮으면 판정 기준부터 다시 맞춤), 엔진 선호율의 95% 하한 > 50%.
- 판정 전에는 엔진 추천을 "전문가 검증"으로 표현하지 않습니다.

## 6. 하지 않는 것

- 결과를 보고 판정 기준·통과선·시나리오를 고르는 것.
- 통과율만 보고하고 구간·실패 사례를 빼는 것.
- 규칙 판정 통과를 "추천이 효과적"이라는 근거로 쓰는 것.
