## 해석
- v0.3의 '비·미세먼지 때 실내 시설 우선' 규칙은 판정자에게 일관되게 선호됨(비·PM2.5에서 엔진 우세).
- 맑은 날에는 거의 모든 사례에서 '가까운 곳 1순위' 기준선이 선호됨. 메모의 공통 이유는 1순위 시설의 이동 부담(예: 서울 출발 2.4시간 횡성이 1순위). 엔진은 허용시간 안이면 이동시간을 순위에 약하게만 반영함.
- 판정자는 시설의 효과 근거·환경 자료를 보지 못하고 이동시간·실내 표시만 봄. 이 구조에서는 '가까운 곳'이 유리하게 판정될 수밖에 없는 한계가 있음(순환·정보 비대칭).
- 다음 판 검토 거리: 정신건강 상태가 심하거나 피로가 높을 때 이동시간 가중을 키우는 규칙. 이 판정 결과를 보고 바꾸면 사후 조정이므로 EVALUATION.md 변경 기록에 남기고 전문가 판정으로만 확인할 것.
