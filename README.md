# 숲결 (Soopgyeol) — 산림치유 맞춤 추천 웹 프로토타입

기상환경 · 지역환경 · 임상도 · 치유목적 **4축 가중합 모델**로 산림치유 시설과
**산림치유 프로그램**을 추천하는 대국민 서비스 프로토타입입니다.
서비스 1차 범위는 2026 효과측정 자료의 **운영기관 16개**이며, 현재 점수는 근거 확보 전의 **시연값**입니다.
경상국립대학교 산림환경자원학과 인간환경연구실(HEL&FEI) 시연용입니다.

빌드가 필요 없는 정적 웹앱입니다. `index.html`을 열거나 어떤 정적 호스팅(GitHub Pages, Vercel, Netlify, S3)에
폴더째 올리면 그대로 동작합니다.

## 맞춤 추천 엔진 v0.4 (2026-11-15 추가)

화면 결과 영역 맨 위의 **'지금 내 상태에 맞는 치유의 숲'** 카드가 새 엔진입니다.
상태 자가점검(6영역)·목적·걷기·이동 허용·방문일·출발 위치를 넣으면 설문 효과모형과 방문일 환경(예보·기후),
이동시간을 합쳐 추천하고 **순위 범위(10~90%)**와 근거 등급(효과측정 자료 기반 / 유사 시설로 추정 / 문헌 근거 기반)을 표시합니다.
방문이 어려우면 디지털치료제(연결 자리) → 집 근처 수관 피복 30% 이상 공원 → 가까운 휴양림·치유의숲을 안내합니다.
구조·자료 출처·제한은 [`docs/ALGORITHM.md`](docs/ALGORITHM.md)에 있습니다. 아래의 4축 가중합 화면은 기존 시연 화면으로 그대로 둡니다.

- 예보·미세먼지 자동 갱신: 저장소 Secrets에 `DATA_GO_KR_KEY`를 등록하면 `.github/workflows/env-daily.yml`이 하루 2회 `data/env_today.json`을 갱신합니다.
- 시험: `node tests/engine.test.mjs`

## 웹·앱·API 공용 구조 (2026-11-16 추가)

같은 추천 엔진을 웹(GitHub Pages)·앱(Capacitor)·API 서버(컨테이너·쿠버네티스)가 함께 씁니다.
기본값은 지금처럼 **브라우저 안 계산**이며, `config.js`의 `apiBase`를 채울 때만 서버로 계산을 보냅니다.
계획·검증 결과·한계는 [`docs/PLATFORM_MIGRATION.md`](docs/PLATFORM_MIGRATION.md), API 명세는 [`docs/api/openapi.yaml`](docs/api/openapi.yaml)에 있습니다.

```bash
npm test                         # 엔진 시험 + API 동등성 시험
npm start                        # API 서버(http://localhost:8080, 외부 패키지 없음)
docker build -t soopgyeol-api .  # 컨테이너
kubectl apply -k deploy/k8s      # 쿠버네티스(초안, 클러스터 미검증)
```

## 실행

```bash
# 로컬 확인
python3 -m http.server 8000
# 브라우저에서 http://localhost:8000 접속
```

외부 CDN을 사용합니다(인터넷 필요): Leaflet 1.9.4(unpkg), OpenStreetMap 타일,
Pretendard(jsDelivr), Noto Sans/Serif KR(Google Fonts).
지도 라이브러리 로드가 실패하면 좌표 기반 간이 지도로 자동 대체됩니다.

## 2027 연구계획 반영(2026-11-15)

연구설계 5장 '프로토타입 대조와 반영'의 12개 항목을 화면에 반영했습니다. 항목별 상태는 「알고리즘·데이터」 모달 하단 표에 있습니다.

- **시설 범위**: 1차 범위 16개 기관을 표시합니다. 진흥원 소속기관 중 프로그램 운영시설 후보 13곳(F02~F14)을
  '효과측정 기관 후보'로 두고, 프로토타입에만 있던 6곳은 '유사 시설로 추정'으로 표시합니다.
  진흥원 시설 6곳(장성숲체원·청도숲체원·대전숲체원·양평치유의숲·김천치유의숲·곡성치유의숲)은 이름·주소·좌표만 넣고
  '프로필 구축 전'으로 따로 보여 주며 점수를 계산하지 않습니다. 나머지 3곳은 명단 대조 전이라 '미확인'으로 둡니다.
- **시연값 표시**: 가중치, 열쾌적 구간(18~23℃), 습도·PM2.5 점수, 치유 인자 가점, 목적 프로파일에 '시연값'을 붙이고
  `data.js`의 `DEMO_PARAMS`로 목록화했습니다. 가중치 조절 막대는 기관 시연용으로 유지합니다.
- **점수 두 층**: 카드 점수를 '예측 효과 층'(기상·임상·목적)과 '접근·편의 층'(지역환경)으로 나눠 보여 줍니다.
- **치유 목적 근거 유형**: 스트레스는 '효과측정 자료 기반', 수면·호흡기·가족·활력은 '문헌 근거 기반'으로 표시합니다.
- **프로그램 속성(D1)**: 난이도·실내외·목적 태그·악천후 대체를 상세 화면에 모두 표시합니다.
- **시설 속성(D5)**: 무장애 여부, 지형, 접근성, 실내 시설, 근거 수준과 시설ID를 상세 화면에 표시합니다.
- **피톤치드**: 진흥원 누리집 '피톤치드 측정결과' 게시 여부로 시설별 근거 수준 문구를 붙였습니다. 측정값은 아직 반영하지 않았습니다.
- **기온감률**: 연구설계 3.4절의 표준값 0.65℃/100m로 바꾸고, 근거 없던 '숲 내부 체감 보정 0.85'를 뺐습니다.
- **개인정보**: 로그인·저장·전송이 없음을 화면에 명시했습니다(코드에도 저장소·네트워크 호출 없음).

## 추천 알고리즘

```
종합 적합도 S = 0.32·W(기상) + 0.18·R(지역환경) + 0.22·S_stand(임상도) + 0.28·P(목적)
```

- **W 기상적합도**: 표고 보정 기온 = 기온 − 표고/100 × 0.65℃ → 열쾌적 구간(18~23℃)과의 거리(40%),
  습도 55% 기준 이탈 보정(14%), PM2.5 좋음/보통/나쁨 = 100/72/28 + 실내 프로그램·수관울폐도 완충(26%),
  강수 시 숲의 실내 대체 역량(치유센터·숙박·움막)과 풍속 감점(20%)
- **R 지역환경**: 출발 권역 → 숲 권역 편도 이동시간(60%), 지형·경사 × 보행 선호 적합(25%), 표고 적합(15%)
- **S 임상도**: 주임상 × 목적 친화도 행렬 + 수종이 가진 치유 인자(피톤치드·음이온·경관·차광) 가중,
  영급(장령림)과 수관울폐도 반영
- **P 목적 적합도**: 숲별 목적 프로파일 + 해당 목적 태그를 가진 프로그램 수 + 보행 선호와 난이도 정합성

축별 점수는 분포 확장(거듭제곱 변환)을 거쳐 상위 구간에 몰리지 않게 펼칩니다.
가중치는 「알고리즘·데이터」 모달에서 직접 조정할 수 있고(기본형·기상민감형·목적중심형·균등형 프리셋),
네 축의 비율이 순위를 어떻게 바꾸는지 시연할 수 있습니다.

프로그램은 목적 태그·난이도·기상 조건으로 점수를 매겨 2개를 고르며, 비 또는 PM2.5 나쁨에서는
실내·저강도 프로그램을 우선 편성하고 `실내 전환` 배지와 대체 프로그램을 함께 표시합니다.
